# Security policy

## Reporting a vulnerability

Email security reports to support@macdns.app with "Security" in the subject. Do not open a public issue for a vulnerability.

Include the MacDNS version (shown at the bottom of the Settings sidebar), the macOS version, and the steps that reproduce the problem. A proof of concept helps.

Please keep the details private until a fixed version is released.

## Supported versions

Only the latest release receives security fixes. MacDNS updates itself, so a fix reaches installed copies through the normal update.
